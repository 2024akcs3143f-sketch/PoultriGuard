# PoultriGuard

**An AI-Based Poultry Disease Detection, Early Warning and Farm Management System for Smallholder Farmers in Uganda**

## 1. Project Overview

PoultriGuard is a Bachelor of Computer Science project proposed to support smallholder poultry farmers and agricultural extension officers in Uganda. The system is intended to provide AI-assisted preliminary poultry disease screening, symptom-based decision support, locality-based early-warning alerts and digital farm record management.

The project focuses on improving access to organised poultry health information and supporting timely reporting and review of suspected disease cases. System predictions are preliminary and do not replace diagnosis by a qualified veterinary professional.

## 2. Project Objectives

- Develop an AI-assisted poultry disease screening component using images and reported symptoms.
- Provide disease information and appropriate referral guidance.
- Develop a locality-based early-warning mechanism for reviewing suspected disease patterns across farms.
- Provide digital records for vaccination, mortality, feed use and egg production.
- Evaluate the system's functionality, classification performance and usability.

## 3. Main Features

- Farmer registration and login.
- Farmer, extension officer and administrator dashboards.
- Image-assisted disease screening.
- Symptom-based disease screening.
- Disease information and referral guidance.
- Locality-based suspected outbreak alerts.
- Farm management and production records.
- Disease report review and status management.
- Reports and data export, where implemented.

## 4. Proposed Technology Stack

- **Frontend:** HTML, CSS and JavaScript.
- **Backend:** Python with Flask.
- **Database:** MySQL.
- **AI/ML:** TensorFlow/Keras and MobileNetV2 for image classification, subject to data availability and evaluation.
- **Symptom screening:** Python-based decision-tree logic.
- **Development tools:** Visual Studio Code, Git and GitHub.

These are the proposed technologies; the final stack may be adjusted during implementation.
